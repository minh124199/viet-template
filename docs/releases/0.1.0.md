# Viet Template 0.1.0 Release Notes

**Release Date**: 2026-09-06
**Maturity**: Pre-1.0 Public Release

---

## 1. Highlights

Viet Template 0.1.0 is the initial public release of Viet Template, a compile-first, low-allocation JVM template engine featuring Velocity Template Language (VTL) compatibility.

This release introduces:
- **Public API & Runtime**: Core abstractions (`TemplateEngine`, `Template`, `RenderContext`, `TemplateOutput`), streaming output buffers, contextual escaping (`HTML`, `XML`, `JAVASCRIPT`), and diagnostic models.
- **Language & AST**: Clean-room Pratt parser and lexer supporting complete VTL grammar (references, directives, expressions, ranges, and string interpolation) with an immutable AST model.
- **VTL Reference Interpreter**: Complete reference interpreter supporting standard 3-state evaluation semantics (`UNDEFINED`, `DEFINED_NULL`, `DEFINED_VALUE`), Velocity 2.x `LINES` mode whitespace gobbling, loop metadata, and block macros.
- **Safe Introspection & Security**: Secure-by-default execution profile restricting dangerous reflection pivots and enforcing strict limits on iterations, recursion, and output sizes.
- **Differential Compatibility Baseline**: Comprehensive test harness verifying behavior side-by-side against official Apache Velocity Engine 2.4.1.
- **Dual Build Parity**: Full build support under both Apache Maven 3.9+ and Gradle 8.12 with byte-for-byte binary parity.

## 2. Compatibility Baseline

> **Canonical Compatibility Statement**:
> Apache Velocity 2.4.1 differential compatibility: **295/301 scenarios exact (98.01%)**, **5 documented intentional differences**, **1 Viet Template extension**, **0 unsupported scenarios**, and **0 unclassified regressions** (**100.00% accounted behavior coverage** across 20 active functional categories).

Viet Template achieves predictable, documented compatibility with Apache Velocity Engine 2.4.1 while intentionally diverging in key areas for security and safety.

---

## 3. Known Intentional Differences & Extensions

The six classified differences and extensions against Apache Velocity 2.4.1 are:

1. **Divide-by-Zero (`arithmetic.divide-by-zero`)**: Velocity logs a warning and returns `null` (rendering literal `$x`). Viet Template fails fast with a `TemplateRenderException` (`DIVISION_BY_ZERO`).
2. **`.class` Property Denial (`security.denial.class-property`)**: Velocity permits `$obj.class` reflection by default. Viet Template's safe execution profile blocks `.class` access to prevent sandbox escapes.
3. **`getClass()` Method Denial (`security.denial.get-class-method`)**: Velocity permits `$obj.getClass()` by default. Viet Template's safe profile denies reflection access.
4. **Legacy Null-RHS Preservation for Undefined (`set.null-rhs.legacy-preserved.undefined`)**: Velocity 2.x unconditionally overwrites existing context keys with `null`. Viet Template provides an optional compatibility mode preserving Velocity 1.x variable-preservation semantics.
5. **Legacy Null-RHS Preservation for Method Null (`set.null-rhs.legacy-preserved.method-null`)**: Like undefined references, Viet Template allows preserving prior values when a method returns `null` under the legacy compatibility configuration.
6. **Programmatic Loop Termination (`foreach.control.stop-method`)**: Velocity 2.4.1 removed `$foreach.stop()`. Viet Template retains `$foreach.stop()` as an extension alongside `#break` to ease migration of legacy templates.
